# UmbSocial issues and discussions

The public place to report problems with [UmbSocial](https://docs.umb.social), ask questions and suggest ideas. UmbSocial is closed source, so there is no code here.

* **[Report a bug](https://github.com/UmbHost/UmbSocial-Issues/issues/new/choose)**: something in UmbSocial doesn't work as the [documentation](https://docs.umb.social) says.
* **[Ask a question](https://github.com/UmbHost/UmbSocial-Issues/discussions/categories/q-a)**: help with setting up or using UmbSocial.
* **[Suggest an idea](https://github.com/UmbHost/UmbSocial-Issues/discussions/categories/ideas)**: something you'd like UmbSocial to do.

## Support

The free edition has community support only, here. It doesn't include support tickets.

With a paid licence, you can also [open a support ticket](https://docs.umb.social/17/support/support-tickets/) through UmbPanel.

## Before you post

Everything here is public. Never include licence keys, access tokens, app passwords, webhook addresses, client secrets or personal data, and check logs and screenshots for them. If you have posted one by mistake, revoke it straight away.

Please don't report security problems here.
